PROJECT OVERVIEW

⚛️ What Is QRNG Hub?

The Quantum Random Number Generator Hub is an interactive web platform that bridges quantum computing theory and hands-on understanding. By connecting to IBM Quantum hardware via Qiskit, the platform generates genuinely unpredictable numbers rooted in quantum mechanical uncertainty — something no classical computer can truly replicate.

Classical computers use deterministic algorithms like Linear Congruential Generators (LCG) that only appear random: given the same seed, they will always reproduce the same sequence. This makes them fast and reproducible, but fundamentally predictable if the internal state is ever known. Quantum randomness works differently — it exploits the fundamental superposition and measurement collapse of qubits, so the outcome of a measurement is not merely hard to predict, it is provably undetermined until the moment it's observed.

QRNG Hub was built to make that distinction tangible rather than abstract. Instead of reading about quantum uncertainty in a textbook, visitors can put a qubit into superposition, measure it on real IBM quantum hardware, and watch the classical and quantum generators produce their sequences side by side — then run standard NIST statistical randomness tests to see how each holds up under scrutiny.

How It Works

Each request routes to one of two very different engines behind a single interface:

  • Classical path — a seeded LCG computes the next value with simple arithmetic, deterministic and instant.
  • Quantum path — a Flask/Python backend builds a Qiskit circuit, puts a qubit into superposition, and sends it to IBM Quantum hardware for measurement.
  • Results stream back through a REST API and render live with Chart.js and the Canvas API.
🌐

Why It Matters

Randomness quality isn't academic trivia — it underpins real systems:

  • Cryptography — predictable keys are breakable keys; true randomness closes that gap.
  • Security — tokens, nonces, and one-time pads all depend on unpredictability.
  • Simulation — Monte Carlo methods and fair-chance systems (like the Lottery Gen demo) need generators free of hidden patterns.
